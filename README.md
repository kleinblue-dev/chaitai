# 拆台 · Chaitai

一个不听话的 2D 横版动作游戏。单文件 HTML5 Canvas，**零依赖、零外部素材**——画面与音效全部由代码程序化生成。

![标题](screenshots/title.png)
![开场](screenshots/opening.png)

## 玩

- 双击 `index.html` 即可（`file://` 直接运行）；也可以用任意静态服务器打开。
- 无需构建、无需安装依赖。

| 操作 | 键 |
|---|---|
| 移动 | A / D 或 ← / → |
| 跳跃 | 空格 / W / ↑ |
| 攻击 | J 或 Z（长按蓄剑气） |
| 冲刺 | K 或 X（冲刺中按 J＝居合） |
| 静音 | M |
| 重开 | R（死亡后） |

触屏设备会自动显示屏幕按钮。

## 内容

- 序章 + 五幕 + Boss + 四种结局。
- 一个会「记账」的旁白：它会回应你的真实行为（完美闪避、连击、撞墙、站台看戏……），也会因为你拆台而翻脸。
- 当前公开版本为**阶段 2 垂直切片收口版**（2026-10-17）：序章 + 第一幕 + 幕终精英「大灯」；五幕与 Boss 均已接线可玩。

## 测试与证据

`tools/` 是开发期的本机测试仪器：结构/行为/像素/轨迹/性能/变异证伪共 **39 个闸**，另有切片节奏与一次性诊断脚本。

- 依赖：Node.js、`puppeteer-core`、Edge/Chromium。
- 脚本里的 Edge 与 `puppeteer-core` 路径是作者本机路径（`D:/2006L/...`），运行前请改成你的路径。
- 最近一次全套（作者本机 Windows 11 + Edge）：**PASS 39 / FAIL 0**，约 68 分钟（2026-10-17）。
- **口径**：单机数据，不代表所有设备；不声称「无 bug」，也不声称「所有设备 60fps」。

运行全套：

```bash
bash tools/_run-suite.sh
```

## 目录

| 路径 | 说明 |
|---|---|
| `game.js` | 全部游戏逻辑/渲染/音频（单文件） |
| `index.html` | 入口与触屏按钮 |
| `assets/` | 旁白台词表、视觉配置（缺失时安全降级） |
| `tools/` | 测试闸、证伪变异、诊断探针 |
| `versions/` | 历史快照（v0.1.0–v0.1.2） |
| `BASELINE.md` / `KNOWN_ISSUES.md` / `VISUAL_CONSTITUTION.md` | 基线、已知问题、视觉宪法 |

## 设计约束

- 零第三方代码、素材、字体；所有画面/音效程序化生成。
- 不使用任何第三方游戏的角色、名称或素材。
